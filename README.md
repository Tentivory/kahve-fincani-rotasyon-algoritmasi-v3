# Kahve Fincanı Rotasyon Algoritması v3.0

## Giriş

Bu proje, insanlık tarihinin en kritik sorunlarından biri olan **kahve fincanının masanın üzerinde nasıl döneceği** sorununu çözmek için geliştirilmiştir. Yıllar süren (asılında 3 dakika) araştırmalar sonucunda ortaya çıkan bu algoritma, fizik kurallarını, kuantum mekaniğini ve biraz da şansı bir araya getirerek fincanınızın rotasyon açısını hesaplar.

**UYARI:** Bu algoritmayı kullanmadan önce kahvenizi için. Aksi halde fincan dönmez, siz dönersiniz.

## Kurulum

```bash
pip install math random time
# (zaten Python'da var, ama ciddi görünsün diye)
```

## Kullanım

```bash
python kahve_rotasyon.py
```

Program sizden fincanın çapını (cm) ve kahvenin sıcaklığını (Celsius) isteyecektir. Sonra size **kesin** (değil) bir rotasyon açısı verecektir.

## Bilimsel Temel

- Newton'un 3. yasası (fincan itmez, kahve iter)
- Heisenberg'in belirsizlik ilkesi (fincan hem döner hem dönmez)
- Türk kahvesinin mistik güçleri
- Ve biraz da "ne olursa olsun" felsefesi
